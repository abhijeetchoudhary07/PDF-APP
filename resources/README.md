# Store & launcher assets

Everything in this folder is generated by `tools/generate-app-assets.py`. Edit
the colours or proportions in that script and re-run it rather than editing the
PNGs by hand:

```bash
python3 tools/generate-app-assets.py
```

## What is here

| Path | Purpose |
| --- | --- |
| `icon-only.png` (1024×1024) | `@capacitor/assets` source for the legacy square icon |
| `icon-foreground.png` (1024×1024) | Adaptive-icon foreground layer, art kept inside the 66/108 safe zone |
| `icon-background.png` (1024×1024) | Adaptive-icon background layer (brand gradient) |
| `splash.png` / `splash-dark.png` (2732×2732) | `@capacitor/assets` splash sources, safe for `CENTER_CROP` |
| `android/res/**` | A ready-made Android resource tree — mipmaps at all five densities plus portrait/landscape/night splash drawables |
| `play-store/play-store-icon-512.png` | Play Console listing icon: 512×512, 32-bit PNG with alpha, square (Play applies its own mask) |
| `play-store/feature-graphic-1024x500.png` | Play Console feature graphic (required for a listing) |

## Applying them to an Android project

The repository has no `android/` directory yet, so add the platform first:

```bash
npm install --save @capacitor/android @capacitor/splash-screen
npx cap add android
```

Then either let `@capacitor/assets` generate from the sources in this folder:

```bash
npm install --save-dev @capacitor/assets
npx capacitor-assets generate --android --assetPath resources
```

…or copy the pre-rendered tree straight in, which produces the same result
without installing anything:

```bash
cp -R resources/android/res/ android/app/src/main/res/
```

After either route, confirm that
`android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` points its
`<foreground>` at `@mipmap/ic_launcher_foreground` and its `<background>` at
`@mipmap/ic_launcher_background`; `@capacitor/assets` writes that file, the
manual copy does not.

## Play Console checklist these cover

- App icon — 512×512 32-bit PNG with alpha ✔
- Feature graphic — 1024×500 ✔
- Adaptive launcher icon for Android 8.0+ ✔
- Splash for every density, portrait, landscape and dark mode ✔

Still to supply by hand: at least two phone screenshots (minimum 320px on the
short edge, 16:9 or 9:16), and a 7-inch/10-inch tablet set if the listing
declares tablet support.
